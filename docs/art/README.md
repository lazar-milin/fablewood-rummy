# Art production records

This folder preserves the card kit's production materials outside the web server's public directory. They are contributor reference documents, not runtime assets.

- `production/` contains the generation prompts, historical design notes, palette and ornament records, and validation report.
- `SOURCE.json` records the historical import inventory. Some paths describe files that have since been retired or consolidated.
- [ASSETS.md](../../ASSETS.md) is the current provenance and attribution record.

Historical production notes may describe earlier filenames or asset layouts. For current rendering, use `public/card-art.js`, `public/card-art.css`, and the shared files in `public/art/card-kit/assets/`.
